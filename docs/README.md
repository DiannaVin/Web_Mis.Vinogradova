# Dianna Teron - Оптимизированная персональная страница

## 🚀 Оптимизации для мобильных устройств

### Поддерживаемые устройства:
- ✅ iPhone (все модели)
- ✅ iPad (все модели)
- ✅ Android телефоны
- ✅ Android планшеты
- ✅ Все современные браузеры

### Основные оптимизации:

#### 1. **Производительность**
- Автоматическое определение мобильных устройств
- Отключение тяжелых анимаций на слабых устройствах
- Оптимизация анимаций с использованием `requestAnimationFrame`
- Throttling для scroll-событий
- Lazy loading для неважных элементов

#### 2. **Адаптивный дизайн**
- Полная поддержка всех размеров экранов
- Оптимизированные touch-события
- Увеличенные области касания (44px минимум)
- Поддержка landscape ориентации
- Оптимизация для Retina дисплеев

#### 3. **PWA функциональность**
- Service Worker для кэширования
- Манифест для установки как приложение
- Офлайн поддержка
- Push-уведомления (готово к настройке)

#### 4. **SEO и доступность**
- Оптимизированные мета-теги
- Sitemap.xml
- Robots.txt
- Семантическая разметка
- Поддержка screen readers

#### 5. **Безопасность**
- CSP заголовки
- XSS защита
- Clickjacking защита
- Безопасные заголовки

## 📱 Медиа-запросы

### Устройства:
- **1024px+**: Большие планшеты и ноутбуки
- **768px-1024px**: Планшеты (iPad, Android)
- **480px-768px**: Большие телефоны (iPhone Plus, Android Large)
- **375px-480px**: Стандартные телефоны (iPhone, Android)
- **320px-375px**: Маленькие телефоны (iPhone SE, Android Small)
- **<320px**: Очень маленькие экраны

### Ориентация:
- **Portrait**: Вертикальная ориентация
- **Landscape**: Горизонтальная ориентация (оптимизировано)

### Для разработки:

2. Убедитесь, что HTTPS включен
